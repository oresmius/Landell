# Landell

Landell is an experimental software-defined radio (SDR) transceiver project under active development.

The project is named in honor of [Father Roberto Landell de Moura](https://memoria.ebc.com.br/agenciabrasil/noticia/2013-02-13/atualizada-invencao-que-pode-ser-atribuida-um-brasileiro-radio-se-integra-novas-tecnologias), a Brazilian Catholic priest, scientist, and inventor recognized as one of the early pioneers of radio and wireless voice transmission.

## Repository Structure

- `Arquivos Kicad/` — official hardware design, schematics, PCB, and project-specific symbol libraries.
- `Arquivos QSpice/` — simulation schematics, custom symbols, and SPICE models.
- `GNU Radio/` — flowgraphs, Python code, and test signals used in DSP experiments.
- `Documentos/` — project reports and technical conclusions.

## Current Work

Development currently focuses on the power supply, analog I/Q interface, signal conditioning, protection, grounding, circuit simulation, and SDR signal-processing experiments.

KiCad remains the official hardware schematic source. QSpice is used as a separate simulation environment.

## Status

Work in progress. Schematics, simulations, component choices, software, and documentation may change as the project evolves.
